# ログインセッション表示制御の適正化および課題5.5追加計画 (v1.1.0)

## 概要
学習者が混乱しないよう、`th:if` の用途を整理し、第5章に新しい課題を追加することで、一貫性のある学習構成に整える。

## 主な変更内容
1. **ガイド修正**: 演習5に「課題5.5：ログイン・ログアウトボタンの切り替え（th:ifの活用）」を追加。コンテンツの非表示指示（Type 2）を排除。
2. **第4章〜第7章コード修正**: 検索フォームやメニューリストを囲む `th:if`（Type 2）をすべて削除し、常時表示化。
3. **第5章〜第7章レイアウト修正**: ログイン・ログアウトボタンの切り替え（Type 1）のみ `th:if` を適用。

## バージョン履歴
- v1.1.0: 初版（今回の修正を反映）
